📖 What is an Array?

An array is a fixed-size, contiguous block of memory that holds elements of the same type. When you write int[] arr = new int[5] in Java, the JVM reserves 5×4 = 20 bytes of contiguous heap memory, all zeroed out. The address of arr[0] is some base address B, and arr[i] is at B + i×4. This is why random access is O(1) — you don't search; you calculate.

Array: int[] arr = {10, 20, 30, 40, 50} Memory layout (contiguous): ┌──────┬──────┬──────┬──────┬──────┐ │ 10 │ 20 │ 30 │ 40 │ 50 │ └──────┴──────┴──────┴──────┴──────┘ [0] [1] [2] [3] [4] ↑ Base address B addr(arr[i]) = B + i × 4 → O(1) access!

📐 What are 2D Arrays?

A 2D array is an array of arrays — a table with rows and columns. In Java, int[][] matrix = new int[3][4] creates 3 separate 1D arrays, each of size 4. The rows are NOT necessarily contiguous in memory (unlike C's 2D arrays), because each row is an independent object on the heap.

int[][] grid = new int[3][4] → 3 rows, 4 columns grid[0] → [ 0 | 0 | 0 | 0 ] ← one int[] object on heap grid[1] → [ 0 | 0 | 0 | 0 ] ← another int[] object grid[2] → [ 0 | 0 | 0 | 0 ] ← another int[] object Accessing grid[r][c]: • grid[r] → gets the r-th row array O(1) • [c] → gets the c-th element O(1) Traversal: row by row is cache-friendly ✓ column by column is NOT ✗
💡
2D Array Patterns you must know:
• Row/Column traversal: nested for loops
• Diagonal traversal: elements where i == j (main) or i + j == n-1 (anti-diagonal)
• Transpose: swap grid[i][j] ↔ grid[j][i]
• Spiral order: shrinking boundary: top/bottom/left/right
• 2D Prefix Sum: O(1) submatrix sum queries (covered in this lecture)

🧵 What is a String in Java? — The Deep Dive

In Java, a String is an immutable sequence of char values. Internally, it is backed by a char[] (before Java 9) or a byte[] with a coder flag (Java 9+ compact strings). "Immutable" means once a String object is created, it cannot be changed — ever. Any operation that appears to "modify" a string actually creates a brand new String object.

String s = "hello"; s = s + " world"; // What ACTUALLY happens: Step 1: Create new object "hello world" (new heap allocation) Step 2: Point s to the new object Step 3: "hello" is now UNREFERENCED → eligible for GC If done 1000 times in a loop: → 1000 new String objects created! → O(1+2+3+...+N) = O(N²) time ← The String concatenation trap
⚠️
The StringBuilder Fix: StringBuilder is a mutable buffer. It holds a resizable char[] array internally and appends directly — no new objects. Use StringBuilder inside any loop that builds a string.

Complexity comparison:
String += char in a loop → O(N²) time
StringBuilder.append(char) in a loop → O(N) time, O(1) amortized per append
☕ Java · String vs StringBuilder Deep Dive 
// String — immutable, stored in String Pool

📊 Prefix Sums (1D and 2D)

Imagine your bank account. If you want to know exactly how much you spent between Wednesday and Friday, you don't need to manually add up Wednesday + Thursday + Friday's receipts. You can simply look at your total balance on Friday and subtract your total balance from Tuesday!

This is the essence of Prefix Sums. They allow you to answer multiple Range Sum Queries in O(1) time after a single O(N) precomputation step.

1.1 The 1D Memory Logic

We build a new array P where P[i] stores the sum of all elements from index 0 up to i.

// Original Array (Daily Expenses): arr = [ 3, 1, 4, 1, 5 ] // Prefix Sum Array (Cumulative Spending): P[0] = 3 P[1] = P[0] + 1 = 4 P[2] = P[1] + 4 = 8 P[3] = P[2] + 1 = 9 P[4] = P[3] + 5 = 14 P = [ 3, 4, 8, 9, 14 ]
📝 Prefix Sum · Logic
// Step 1: Precompute (Build Prefix Array)
P[0] = A[0]
for (int i = 1; i < N; i++) {
   P[i] = P[i-1] + A[i];
}

// Step 2: Query(L, R) in O(1)
return P[R] - (L > 0 ? P[L-1] : 0);

1.2 The 2D Submatrix Logic

What if you have a 2D matrix (like a grid of numbers) and you want the sum of a specific rectangle? Treating the matrix as a series of rectangles. Doing nested loops takes an incredibly slow O(N²M²). Using the Inclusion-Exclusion Principle, you can find the sum of any sub-rectangle in O(1).

🚀
Optimization Hint: If you are updating values frequently and querying ranges, a vanilla Prefix Array is slow (O(N) updates). Instead, use a Fenwick Tree (BIT) to get O(log N) updates and queries.
Operation Formula Statement
Precompute `P[i][j]` arr[i][j] + P[i-1][j] + P[i][j-1] - P[i-1][j-1]
Add the cell itself + rectangle ABOVE + rectangle LEFT. Subtract corner added twice.
Query `(r1,c1)` to `(r2,c2)` P[r2][c2] - P[r1-1][c2] - P[r2][c1-1] + P[r1-1][c1-1]
Take giant rectangle. Cut top. Cut left. Add top-left corner back once.
📝 2D Submatrix · Logic
// To find sum from (r1, c1) to (r2, c2):
Sum = P[r2][c2] - P[r1-1][c2] - P[r2][c1-1] + P[r1-1][c1-1];

🎒 Kadane's Algorithm — Maximum Subarray

If you're looking for the largest possible sum from a contiguous chunk of an array, checking every chunk takes O(n³). Kadane's algorithm finds the answer in a blazingly fast O(N) single pass!

2.1 The "Reset" Philosophy

Kadane’s works on a simple intuition: If my past is dragging me down (negative sum), I must drop the baggage and start fresh!

At every step, you must make a greedy choice: Do I append the current number to the existing subarray chain, OR do I cut ties and start a brand-new subarray at this exact number?

Let's dry run the array: [-2, 1, -3, 4] [ -2 ] -> currentMax = -2. [ 1 ] -> Do I append 1 to -2 (gives -1)? Or start fresh at 1? (1 > -1. Start fresh!) currentMax = 1 [ -3 ] -> Do I append -3 to 1 (gives -2)? Or start fresh at -3? (-2 > -3. Keep the chain!) currentMax = -2 [ 4 ] -> Do I append 4 to -2 (gives 2)? Or start fresh at 4? (4 > 2. Drop the baggage!) currentMax = 4 Global Max recorded during this trip: 4
☕ Java · Maximum Subarray
public int maxSubArray(int[] nums) {
    int currentMax = nums[0];
    int globalMax = nums[0];
    
    for (int i = 1; i < nums.length; i++) {
        // Core Philosophy: Accept the baggage or ditch it?
        currentMax = Math.max(nums[i], currentMax + nums[i]);
        globalMax = Math.max(globalMax, currentMax);
    }
    return globalMax;
}
🌟
Extensions: You can apply Kadane's logic to find the Max Product Subarray (track both minProduct and maxProduct) or the Best Time to Buy & Sell Stock (track the minPrice).

🗳️ Boyer-Moore Majority Vote

Find the element appearing more than ⌊n/2⌋ times, in a single pass using constant memory. The trick is to pair off every occurrence of the candidate with one occurrence of something else. A true majority element outnumbers everything else combined, so it is the only value that can survive all the cancellations.

📐 Pseudocode · Majority Element 
// A true majority outnumbers everything else combined,
// so it survives every cancellation.
candidate ← none
count     ← 0

for x in nums:
    if count = 0:
        candidate ← x        // nothing left to cancel — adopt x
        count     ← 1
    else if x = candidate:
        count ← count + 1     // a vote for
    else:
        count ← count - 1     // a vote against — they cancel

return candidate

// If a majority is NOT guaranteed, verify in a second pass:
// count occurrences of candidate; it must exceed n / 2.
☕ Java · Majority Element (LC 169) 
int majorityElement(int[] nums) {
    int candidate = 0, count = 0;
    for (int x : nums) {
        if (count == 0) { candidate = x; count = 1; }
        else if (x == candidate) count++;
        else count--;
    }
    return candidate;   // verify in a 2nd pass if majority isn't guaranteed
}
TimeO(n) — one pass SpaceO(1)
💡
Generalises to ⌊n/3⌋
At most two values can appear more than ⌊n/3⌋ times, so keep two candidates and two counters, then verify both at the end (LC 229). With k counters the same cancellation argument finds every element appearing more than ⌊n/(k+1)⌋ times.

🚩 Dutch National Flag (Three-Way Partition)

Invented by Edsger Dijkstra, the DNF approach sorts 0s, 1s, and 2s in a single pass using O(1) space. It maintains 4 strictly defined zones using 3 pointers: low, mid, and high.

  • 0 to low - 1: Confirmed 0s zone.
  • low to mid - 1: Confirmed 1s zone.
  • mid to high: UNEXPLORED zone.
  • high + 1 to N - 1: Confirmed 2s zone.
☕ Java · Sort Colors
public void sortColors(int[] nums) {
    int low = 0, mid = 0, high = nums.length - 1;
    while (mid <= high) {
        if (nums[mid] == 0) {
            swap(nums, low++, mid++);
        } else if (nums[mid] == 1) {
            mid++;
        } else {
            swap(nums, mid, high--);
        }
    }
}

🔄 The Reversal Algorithm (In-Place)

Rotating an array by K steps in O(1) space using three strategic mirror flips.

🔄
The Trick: To rotate [1, 2, 3, 4, 5] by K=2:
  1. Reverse whole: [5, 4, 3, 2, 1]
  2. Reverse first K: [4, 5, 3, 2, 1]
  3. Reverse rest: [4, 5, 1, 2, 3]
☕ Java · Array Rotation
public void rotate(int[] nums, int k) {
    int n = nums.length;
    k %= n;
    reverse(nums, 0, n - 1);
    reverse(nums, 0, k - 1);
    reverse(nums, k, n - 1);
}

🧵 String Immutability

Strings in many languages are immutable. Operations like s += "abc" create brand new objects, leading to O(N²) time when done in loops.

⚠️
The Trap: Never use += on a String inside a loop. Always use StringBuilder for high-performance mutations.

🔑 Rabin-Karp & Rolling Hash

Rabin-Karp enables O(N) substring searching by converting windows to numerical hashes. The Rolling Hash allows O(1) hash updates as the window slides.

Problem 03 · Prefix Products
Product of Array Except Self
🔗 LC 238
Medium Amazon · Meta · Microsoft Prefix/Suffix
›
Problem

Given an integer array nums, return an output array where output[i] equals the product of all elements except nums[i]. Solve without division in O(N) time.

Input: [1, 2, 3, 4] Output: [24, 12, 8, 6] ↑ ↑ ↑ ↑ 2×3×4 1×3×4 1×2×4 1×2×3
Hints
▶Hint 1 — a nudge

Division is banned. What is the answer at index i, in words?

▶Hint 2 — the key idea

Everything to the left times everything to the right. One left-to-right pass builds prefixes into the output, one right-to-left pass multiplies in the suffixes — O(1) extra space.

Solution

output[i] = (product of everything LEFT of i) × (product of everything RIGHT of i). Make two passes: left-to-right to fill prefix products, then right-to-left multiplying in suffix products. No division needed, works even with zeros.

▶ Solution + Dry Run
☕ Java · O(N) time O(1) extra
public int[] productExceptSelf(int[] nums) {
    int n = nums.length;
    int[] out = new int[n];
    // Pass 1: out[i] = product of nums[0..i-1]
    out[0] = 1;
    for (int i = 1; i < n; i++)
        out[i] = out[i-1] * nums[i-1];
    // Pass 2: multiply by suffix product
    int right = 1;
    for (int i = n-1; i >= 0; i--) {
        out[i] *= right;
        right *= nums[i];
    }
    return out;
}
// [1,2,3,4]: left=[1,1,2,6]
// right scan: i=3→6×1=6, i=2→2×4=8, i=1→1×12=12, i=0→1×24=24 ✓
TimeO(N)
SpaceO(1) extra
Problem 04 · Two Pointers
Container With Most Water
🔗 LC 11
Medium Google · Amazon · Meta · Bloomberg Two Pointers
›
Problem

Given height[] where each value is a vertical line's height, find two lines forming a container that holds the most water.

height = [1, 8, 6, 2, 5, 4, 8, 3, 7] lo=0 hi=8 Area = min(1, 7) × 8 = 8 Best: lo=1, hi=8 → min(8,7) × 7 = 49 ← answer
Hints
▶Hint 1 — a nudge

Area is limited by the shorter of the two lines. Which pointer should you move?

▶Hint 2 — the key idea

Start wide, at both ends. Always move the pointer at the shorter line — moving the taller one can never help, since width shrinks either way.

Solution

Area = min(H[lo], H[hi]) × (hi-lo). Start at widest (lo=0, hi=n-1). Moving the taller pointer can never help — it shrinks width AND can't increase height. So always move the shorter pointer.

▶ Solution
☕ Java · Greedy Two Pointers
public int maxArea(int[] h) {
    int lo = 0, hi = h.length - 1, max = 0;
    while (lo < hi) {
        max = Math.max(max, Math.min(h[lo], h[hi]) * (hi - lo));
        if (h[lo] < h[hi]) lo++; else hi--;
    }
    return max;
}
TimeO(N)
SpaceO(1)
Problem 05 · Prefix Sum + HashMap
Subarray Sum Equals K
🔗 LC 560
Medium Meta · Amazon · Google Prefix Sum
›
Problem

Given array nums and integer k, return the total number of subarrays whose sum equals k.

nums=[1,1,1], k=2 Subarrays: [1,1] at 0-1 and [1,1] at 1-2 → Output: 2
Hints
▶Hint 1 — a nudge

Sliding window fails here because negative numbers break the monotonicity.

▶Hint 2 — the key idea

Use prefix sums in a HashMap. At each index, add the count of previously seen prefixes equal to running - k. Seed the map with {0: 1}.

Solution

If prefix[j] - prefix[i] = k, then subarray [i+1..j] sums to k. Rearranged: we need prefix[i] = prefix[j] - k. As we build prefix sums, look up the count of prefix - k in a HashMap. Seed with {0:1} to handle subarrays starting at index 0.

▶ Solution + Trace
☕ Java · Prefix Sum + HashMap
public int subarraySum(int[] nums, int k) {
    Map<Integer, Integer> freq = new HashMap<>();
    freq.put(0, 1);
    int prefix = 0, count = 0;
    for (int num : nums) {
        prefix += num;
        count += freq.getOrDefault(prefix - k, 0);
        freq.merge(prefix, 1, Integer::sum);
    }
    return count;
}
// k=2, [1,1,1]: prefix=1→2→3
// p=2: look up 2-2=0 → {0:1} → count=1
// p=3: look up 3-2=1 → {1:1} → count=2 ✓
TimeO(N)
SpaceO(N)
Problem 06 · Sliding Window
Minimum Size Subarray Sum
🔗 LC 209
Medium Amazon · Google · Meta Sliding Window
›
Problem

Given a positive integer target and array of positive integers, find the minimum length contiguous subarray with sum ≥ target. Return 0 if none exists.

target=7, nums=[2,3,1,2,4,3] Window [4,3]: sum=7, length=2 ← answer
Hints
▶Hint 1 — a nudge

All values are positive, so growing the window only ever increases the sum.

▶Hint 2 — the key idea

Expand right to reach the target, then shrink from the left while the sum still qualifies, recording the length each time.

Solution

Variable sliding window: expand right until sum ≥ target, then shrink left to minimize length. Since all values are positive, shrinking always decreases sum — the window never "wraps around" in a problematic way.

▶ Solution
☕ Java · Variable Sliding Window 
public int minSubArrayLen(int target, int[] nums) {
    int lo = 0, sum = 0, min = Integer.MAX_VALUE;
    for (int hi = 0; hi < nums.length; hi++) {
        sum += nums[hi];
        while (sum >= target) {
            min = Math.min(min, hi - lo + 1);
            sum -= nums[lo++];
        }
    }
    return min == Integer.MAX_VALUE ? 0 : min;
}
TimeO(N)
SpaceO(1)
Problem 07 · Frequency Array
Valid Anagram
🔗 LC 242
Easy Amazon · Meta · Bloomberg Freq Array
›
Problem

Return true if string t is an anagram of s (same characters, same frequencies, any order).

s="anagram", t="nagaram" → true s="rat", t="car" → false
Hints
▶Hint 1 — a nudge

Two strings are anagrams exactly when their letter counts match.

▶Hint 2 — the key idea

int[26], increment for one string, decrement for the other, check all zeros. Compare lengths first as an early exit.

Solution

Use int[26]: increment on each char of s, decrement on t. If all entries are 0 at end → anagram. This is faster than HashMap since char - 'a' maps each letter to 0–25 in O(1).

▶ Solution
☕ Java · int[26] Counter
public boolean isAnagram(String s, String t) {
    if (s.length() != t.length()) return false;
    int[] cnt = new int[26];
    for (int i = 0; i < s.length(); i++) {
        cnt[s.charAt(i) - 'a']++;
        cnt[t.charAt(i) - 'a']--;
    }
    for (int c : cnt)
        if (c != 0) return false;
    return true;
}
TimeO(N)
SpaceO(1) — int[26] constant
Problem 08 · String Column Scan
Longest Common Prefix
🔗 LC 14
Easy Google · Amazon · Adobe String
›
Problem

Find the longest common prefix string among an array of strings. Return "" if none.

["flower","flow","flight"] → "fl" ["dog","racecar","car"] → ""
Hints
▶Hint 1 — a nudge

You could compare the strings pairwise, but there is a simpler scan.

▶Hint 2 — the key idea

Vertical scan: compare character i of every string, stop at the first mismatch or the first string that ends. No sorting needed.

Solution

Vertical scan: for each column index c, check if all strings share the same character. The first mismatch (or a string that ends) is the answer boundary. Return strs[0].substring(0, c).

▶ Solution + Trace
☕ Java · Vertical Scan
public String longestCommonPrefix(String[] strs) {
    for (int c = 0; c < strs[0].length(); c++) {
        char ch = strs[0].charAt(c);
        for (int i = 1; i < strs.length; i++)
            if (c == strs[i].length() || strs[i].charAt(c) != ch)
                return strs[0].substring(0, c);
    }
    return strs[0];
}
// ["flower","flow","flight"]:
// c=0:'f' ✓ c=1:'l' ✓ c=2:'o'≠'i'(flight) → return "fl" ✓
TimeO(S) total chars
SpaceO(1)
